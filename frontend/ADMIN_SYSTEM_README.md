# 管理员系统使用说明

## 概述

这是一个专为管理员设计的事件管理系统，采用深色主题设计，集成了专业的Markdown编辑器，提供完整的事件管理功能。

## 系统特点

### 🎨 深色主题设计
- 采用现代化的深色渐变主题
- 与网站整体风格保持一致
- 专业的视觉体验，适合长时间使用

### 🔐 管理员专用
- 独立的访问入口，不暴露在公共导航中
- 通过 `/admin` 路径访问管理员控制台
- 支持权限控制和访问管理

### 📝 专业Markdown编辑器
- 集成ByteMD专业Markdown编辑器
- 支持GFM、代码高亮、数学公式、Mermaid图表
- 实时预览和编辑模式切换
- 深色主题适配

## 访问方式

### 1. 管理员控制台
访问路径：`/admin`
- 在导航栏点击"管理"按钮
- 或直接访问 `/admin` 路径

### 2. 事件管理
访问路径：`/admin/events`
- 从管理员控制台点击"事件管理"卡片
- 或直接访问 `/admin/events` 路径

## 功能模块

### 🎯 事件管理
- **事件列表**：支持分页、搜索、筛选和排序
- **事件创建**：完整的表单验证和Markdown编辑器
- **事件编辑**：实时编辑和预览
- **事件删除**：安全的删除确认机制
- **数据导出**：支持Excel格式导出

### 📊 统计信息
- 总事件数量
- 即将开始事件数
- 进行中事件数
- 已完成事件数

### 🔍 搜索和筛选
- **关键词搜索**：标题和内容搜索
- **类型筛选**：公告、活动、发布、展览、更新
- **状态筛选**：即将开始、进行中、已完成、已取消
- **优先级筛选**：高、中、低

## Markdown编辑器功能

### 支持的语法
- **基础语法**：标题、段落、列表、链接、图片
- **GFM扩展**：表格、任务列表、删除线
- **代码支持**：行内代码、代码块、语法高亮
- **数学公式**：LaTeX数学公式支持
- **图表支持**：Mermaid流程图和图表

### 编辑器特性
- **实时预览**：编辑和预览模式切换
- **工具栏**：常用语法快捷按钮
- **快捷键**：支持标准Markdown快捷键
- **深色主题**：与系统主题保持一致

## 数据字段说明

### 必需字段
- **标题** (title)：事件标题，最大200字符
- **类型** (type)：事件类型选择
- **内容** (content)：Markdown格式的详细内容

### 可选字段
- **状态** (status)：事件状态，默认"即将开始"
- **优先级** (priority)：事件优先级，默认"中"
- **发布时间** (publish_date)：事件发布时间
- **开始时间** (start_date)：事件开始时间
- **结束时间** (end_date)：事件结束时间
- **封面图片** (cover_image)：事件封面图片URL
- **地点** (location)：事件举办地点
- **标签** (tags)：事件相关标签数组
- **相关链接** (links)：事件相关链接数组
- **摘要** (excerpt)：事件摘要，可自动生成

## 使用流程

### 1. 创建事件
1. 访问事件管理页面
2. 点击"创建新事件"按钮
3. 填写基本信息（标题、类型、状态等）
4. 使用Markdown编辑器编写内容
5. 添加标签和相关链接
6. 点击"创建"按钮保存

### 2. 编辑事件
1. 在事件列表中找到要编辑的事件
2. 点击"编辑"按钮
3. 修改相关信息
4. 使用Markdown编辑器更新内容
5. 点击"更新"按钮保存

### 3. 查看事件
1. 在事件列表中点击"查看"按钮
2. 浏览事件的完整信息
3. 查看渲染后的Markdown内容
4. 可以点击"编辑事件"进行修改

### 4. 删除事件
1. 在事件列表中点击"删除"按钮
2. 确认删除操作
3. 事件将被永久删除

## 技术架构

### 前端技术栈
- **Vue 3**：使用Composition API
- **Element Plus**：UI组件库，深色主题适配
- **ByteMD**：专业Markdown编辑器
- **Vue Router**：路由管理
- **Axios**：HTTP客户端

### 组件结构
```
src/
├── views/
│   ├── AdminView.vue              # 管理员控制台
│   └── EventManagementView.vue    # 事件管理主页面
├── components/
│   ├── EventFormDialog.vue        # 事件创建/编辑对话框
│   └── EventViewDialog.vue        # 事件查看对话框
└── composables/
    └── useEventAPI.js             # 事件API封装
```
